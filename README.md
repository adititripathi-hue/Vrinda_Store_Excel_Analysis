# 📊 Vrinda Store Sales Analysis Dashboard

## Overview

This project focuses on analyzing sales data for Vrinda Store using Microsoft Excel to uncover business insights and support data-driven decision-making.

The objective was to transform raw sales data into an interactive dashboard that provides visibility into customer behavior, sales performance, order trends, and channel effectiveness.

The project demonstrates skills in data cleaning, data analysis, dashboard development, and business reporting using Excel.

## Business Objective

Vrinda Store wanted to understand its sales performance in 2022 and identify opportunities for growth by analyzing customer demographics, order patterns, and sales channels.

The analysis helps answer key business questions such as:

* Who are the primary customers?
* Which states generate the highest sales?
* Which sales channels perform best?
* What product categories contribute most to revenue?
* How do sales vary across months?

## Dataset

The dataset contains over 30,000 customer orders and includes:

* Order Information
* Customer Demographics
* Product Categories
* Sales Amount
* Order Status

* Geographic Data
